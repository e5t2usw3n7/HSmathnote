    结论十：共焦点问题⚓︎

    Abstract

    “椭圆和双曲线共焦点问题”实际上是死记硬背的填选题离心率结论问题，它巧妙地将椭圆和双曲线的离心率或交点坐标联系在一个式子里。

    这个结论本身的推导对双曲线和椭圆定义的考察很有价值，所以不仅要记住这结论，还要记住它的推导过程。

    一、结论描述⚓︎

    对于共焦点\( F_1 \)、\( F_2 \)的双曲线\( E:\frac{x^2}{m^2} - \frac{y^2}{n^2} = 1 \)和椭圆\( C:\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \space (a>b>0) \)，设两曲线相交于\( P(x_P,y_P ) \)，分别记二者的离心率为\( e_1 \)、\( e_2 \)，记\( \angle F_1 P F_2 = \theta \)则有：

    \[ \frac{1-\cos \theta}{e_1^2} + \frac{1+\cos \theta}{e_2^2} = 2 \tag{1} \]
    \[ |x_P| = \frac{a\cdot m}{c}, |y_P| = \frac{b\cdot n }{c} \tag{2} \]
    Note

    这里\( P \)点取左交点或者右交点（上交点或下交点）是无所谓的，只是个简单的对称关系，所以在\( (2) \)式里加入了绝对值。
